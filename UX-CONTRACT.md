# UX contract
Shared forms, navigation, tables and feedback are owned by static/app.js. Native Select/Listbox and Date controls use platform popups. Form errors remain inline; feedback uses a live region. Server pagination is required. Currency en-IN / INR. SMTP credentials are stored only in the ignored local .env file; they are never returned by application APIs. Monetary values are integer paise; invoice snapshots immutable; payments allocated explicitly. Staff can operate billing, admin configures plans, customers see only owned records. No external charge execution. All mutation requests require a session and same-origin JSON.

## Billing and forms
Read form routing identifiers through getAttribute('id'), since named controls can override DOM properties. Persist subscription-line identities for edits. Preserve contracted unit prices, tax rates and billing cycles unless explicitly repricing. Overdue filters include partial payments. Expiry closing is independent of the invoice schedule and retains historical billing obligations. A report generated by tests with a DOM adapter does not count as browser visual verification.
